Подключение библиотек и препроцессор (Директивы)```cpp\#include <iostream>\#include <cmath>using namespace std;```> 📑 \*\*Описание работы:\*\*> Мы используем директиву `#include <iostream>` для активации потоков ввода и вывода данных на экран дисплея (`cin`, `cout`). Также подключаем `#include <cmath>` для использования математической функции вычисления степени `pow(x, y)`. Инструкция `using namespace std` позволяет использовать стандартное пространство имен без префикса `std::`.\---\### 2. Главная функция и расчет через тип FLOAT (Потеря точности)```cppint main() {&#x20;   float a\_f = 1000.0f;&#x20;   float b\_f = 0.0001f;&#x20;   float part1\_f = pow(a\_f - b\_f, 5);&#x20;   float part2\_f = pow(a\_f, 5) - 5 \* pow(a\_f, 4) \* b\_f;&#x20;   float numerator\_f = part1\_f - part2\_f;&#x20;   float denominator\_f = -10 \* pow(a\_f, 3) \* pow(b\_f, 2) + 10 \* pow(a\_f, 2) \* pow(b\_f, 3) - 5 \* a\_f \* pow(b\_f, 4) + pow(b\_f, 5);&#x20;   float result\_float = numerator\_f / denominator\_f;&#x20;   cout << "Result with FLOAT:  " << result\_float << endl;```> 📑 \*\*Описание работы:\*\*> Здесь мы объявляем переменные `a` и `b` с одинарной точностью памяти `float` (32 бита). Программа разбивает сложную формулу на логические промежуточные части (`part1\_f`, `part2\_f`), вычисляет отдельно числитель (`numerator\_f`) и знаменатель (`denominator\_f`). Из-за аппаратного ограничения разрядной сетки типа `float` при возведении огромного числа 1000 в 5 степень происходит \*\*критическая потеря точности (Precision Loss)\*\*, и результат вычислений на экране получается неверным.\---\### 3. Расчет через тип DOUBLE (Высокая точность)```cpp&#x20;   double a\_d = 1000.0;&#x20;   double b\_d = 0.0001;&#x20;   double part1\_d = pow(a\_d - b\_d, 5);&#x20;   double part2\_d = pow(a\_d, 5) - 5 \* pow(a\_d, 4) \* b\_d;&#x20;   double numerator\_d = part1\_d - part2\_d;&#x20;   double denominator\_d = -10 \* pow(a\_d, 3) \* pow(b\_d, 2) + 10 \* pow(a\_d, 2) \* pow(b\_d, 3) - 5 \* a\_d \* pow(b\_d, 4) + pow(b\_d, 5);&#x20;   double result\_double = numerator\_d / denominator\_d;&#x20;   cout << "Result with DOUBLE: " << result\_double << endl;```> 📑 \*\*Описание работы:\*\*> В этом блоке мы дублируем вычисления, но используем тип данных двойной точности `double` (64 бита). Благодаря увеличенной разрядной памяти, компьютер успешно сохраняет все мелкие знаки после запятой при работе с большими числами. Результат деления получается абсолютно точным математически и равен \*\*1.00000\*\*.\---\### 4. Вычисление выражений инкремента и декремента (Задание 2)```cpp&#x20;   int n = 5, m = 5;&#x20;   // Выражение 1: n++ \* ++m&#x20;   int res1 = n++ \* ++m;&#x20;   cout << "1) n++ \* ++m = " << res1 << " (After: n=" << n << ", m=" << m << ")" << endl;```> 📑 \*\*Описание работы:\*\*> Мы инициализируем переменные `n` и `m` со значением 5. В выражении используется \*\*префиксный инкремент\*\* `++m` (значение увеличивается сразу до умножения и становится равным 6) и \*\*постфиксный инкремент\*\* `n++` (значение увеличивается до 6 только ПОСЛЕ умножения). Таким образом, операция умножения принимает вид: \\(5 \\times 6 = 30\\).\---```cpp&#x20;   n = 5; m = 5; // Сброс значений&#x20;   // Выражение 2: --m < n--&#x20;   bool res2 = --m < n--;&#x20;   cout << "2) --m < n-- = " << (res2 ? "True (1)" : "False (0)") << endl;```> 📑 \*\*Описание работы:\*\*> Сбрасываем переменные обратно к 5. Выполняется логическая бинарная операция сравнения "меньше" (`<`). Префиксный декремент `--m` уменьшает значение немедленно до 4. Постфиксный декремент `n--` оставляет число 5 для операции сравнения. Сравниваем: \\(4 < 5\\), это логическая Истина (`True`), поэтому программа выводит на экран `1`.\---```cpp&#x20;   n = 5; m = 5; // Сброс значений&#x20;   // Выражение 3: m++ > n++&#x20;   bool res3 = m++ > n++;&#x20;   cout << "3) m++ > n++ = " << (res3 ? "True (1)" : "False (0)") << endl;&#x20;   return 0;}```> 📑 \*\*Описание работы:\*\*> Финальное логическое сравнение. Оба инкремента являются постфиксными (`m++` и `n++`), это означает, что в самом сравнении участвуют их первоначальные значения из памяти. Сравниваем: \\(5 > 5\\), что является Ложью (`False`), поэтому результат равен `0`. В конце оператор `return 0` успешно завершает главную функцию программы.\---\## 📊 Сводное объяснение полученных результатов (Conclusion)| Используемый Тип | Описание эффекта памяти | Финальный результат | Соответствие теории || :---: | :--- | :---: | :---: || \*\*`FLOAT` (32-bit)\*\* | Округление из-за нехватки бит памяти | \*\*Неверное число (0.00)\*\* | Ошибка округления || \*\*`DOUBLE` (64-bit)\*\* | Полное сохранение дробной сетки числа | \*\*1.00000\*\* | Идеальный расчет |
