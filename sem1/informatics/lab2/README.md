## 💻 Разбор и подробное объяснение исходного кода



### 1. Подключение библиотек для математики и форматирования вывода

```cpp

#include <iostream>

#include <cmath>

#include <iomanip>



using namespace std;

```

> 📑 **Объяснение работы кода:**

> Мы подключаем директиву `#include <iostream>` для ввода и вывода данных. Также добавляем `#include <cmath>` для работы с функцией возведения в степень `pow()`. Очень важная библиотека здесь — `#include <iomanip>`, она необходима для управления шириной столбцов и количеством знаков после запятой при выводе таблицы.



---



### 2. Инициализация управляющих переменных числового ряда

```cpp

int main()
 {

&#x20;   double sum = 0.0;       

&#x20;   double epsilon = 1e-4;  

&#x20;   double an = 0.0;        

&#x20;   int n = 1;              

```

> 📑 **Объяснение работы кода:**

> Внутри главной функции мы объявляем переменные с высокой точностью `double`. `sum` будет накапливать общий результат сложения, `epsilon` хранит порог точности 0.0001. Переменная `an` выделена для хранения значения текущего члена ряда, а `n` — это счетчик итераций, начинающийся с 1 согласно математическому правилу ряда.



---



### 3. Запуск итерационного цикла вычислений

```cpp

&#x20;   while (true)
 {

&#x20;       an = (2.0 * n + 1.0) / pow(3.0, n);

&#x20;       sum += an;

```

> 📑 **Объяснение работы кода:**

> Мы запускаем бесконечный цикл `while(true)`. На каждой итерации программа рассчитывает значение текущего члена ряда `an` по формуле Варианта 28. Сразу после расчета это значение прибавляется к общей сумме `sum` с помощью оператора совмещенного присваивания `+=`.



---



### 4. Вывод итерационной таблицы и проверка условия останова

```cpp

&#x20;       cout << n << "\\t" << fixed << setprecision(6) << an << "\\t" << sum << endl;



&#x20;       if (an < epsilon)
             {

&#x20;           break;

&#x20;       }

&#x20;       n++; 

&#x20;   }

```

> 📑 **Объяснение работы кода:**

> Манипулятор `fixed` и `setprecision(6)` принудительно отображают 6 знаков после запятой, чтобы наглядно видеть затухание членов ряда. Конструкция `if (an < epsilon)` проверяет условие: если текущее слагаемое стало меньше заданной точности 0.0001, оператор `break` немедленно завершает работу цикла. Если условие не выполнено, счетчик увеличивается (`n++`) и цикл повторяется.



---



### 5. Вывод финального результата

```cpp

&#x20;   cout << "Final Sum of the series: " << fixed << setprecision(4) << sum << endl;

&#x20;   cout << "Total iterations (n): " << n << endl;



&#x20;   return 0;

}

```

> 📑 **Объяснение работы кода:**

> После выхода из цикла программа выводит на экран окончательную сумму ряда с точностью до 4 знаков после запятой, а также показывает общее число пройденных шагов `n`. Оператор `return 0` завершает выполнение программы.
