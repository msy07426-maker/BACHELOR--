Дополнительная функция вычисления факториала```cppdouble factorial(int num) {&#x20;   double fact = 1.0;&#x20;   for (int i = 1; i <= num; i++) {&#x20;       fact \*= i;&#x20;   }&#x20;   return fact;}```> 📑 \*\*Объяснение работы кода:\*\*> Так как в формуле Варианта 28 присутствует математический знак факториала \\((2n+1)!\\), мы создаем отдельную функцию `factorial`. Она принимает число и через цикл умножает элементы, возвращая итоговое значение типа `double`, чтобы избежать переполнения памяти целых чисел.\---\### 2.
